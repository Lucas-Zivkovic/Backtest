# Backtest

A small event-driven backtesting engine for cross-sectional equity strategies, with realistic transaction costs, market-impact modeling, and a performance/metrics layer.

## Overview

The engine steps through a price history one date at a time, asks a `Strategy` for target portfolio weights based only on data available up to that date, and accounts for the cost of rebalancing into those weights. It's built for research on signal-driven, dollar-neutral or long/short equity strategies (momentum, mean reversion, and combinations of the two).

## Project layout

```
BacktestEngine.py       Event loop: iterates the data source, computes P&L and trading costs per step
DataLoader.py           Downloads/caches OHLCV data (yfinance) and Fama-French factor data (pandas-datareader)
Transaction.py          Transaction cost, spread cost, and square-root market-impact models
PositionSizing.py       Converts signals into portfolio weights (dollar-neutral, signed, inverse-vol, Kelly, risk parity...)
PerformanceAnalyzer.py  Turns positions/prices into portfolio returns and a summary metrics table
Metrics.py               Sharpe, Sortino, drawdown, hit ratio, payoff ratio, expectancy, turnover
OrnestUhlenbeck.py       Ornstein-Uhlenbeck process calibration (method of moments + MLE) used by MeanReversion
strategies.py            Signal helpers (momentum, log returns, HMM regime detection, Fama-French regression)
Transaction.py           Cost models used by the engine

Strategies/
  Strategy.py                     Abstract base class: implement signal(), positions() defaults to dollar-neutral
  Momentum.py                     12-1 style trailing momentum (Jegadeesh-Titman)
  CrossSectionalMomentumStrategy.py  Ranks tickers by momentum, goes long top / short bottom decile
  MeanReversion.py                Per-ticker OU calibration + ADF test, mean-reversion signal
  PortfolioCombiner/
    PortfolioCombiner.py          Abstract base for combining several strategies
    Uniform.py                   Equal-weight (1/n) combination of sub-strategies

data/    Cached CSV downloads (OHLCV, Fama-French factors) keyed by tickers/date range/interval
plots/   Backtest output charts (cumulative return, step P&L, step cost) generated by the test suite
```

## How it works

1. A data source exposes `iterate(start_date, end_date)`, yielding `(date, market_data)` pairs where `market_data` is the growing window of OHLCV history up to and including `date`.
2. At each step, `BacktestEngine` passes the price history *excluding* the current date to `strategy.positions(...)` to get target weights (no look-ahead).
3. The change in weights since the previous step (`turnover`) determines trading costs: a percentage transaction cost, half-spread cost, and a square-root market-impact cost based on order size relative to average volume and realized volatility.
4. Step P&L is `(target_positions * today's_return).sum() - cost`. Signals, positions, costs, and results are recorded at every step.

A `Strategy` only needs to implement `signal(prices) -> DataFrame` (a per-ticker score using no future data); the default `positions()` demeans the signal and normalizes it to unit gross exposure (dollar-neutral). Strategies can override `positions()` for other sizing schemes (see `CrossSectionalMomentumStrategy`, `MeanReversion`).

## Setup

This project uses [uv](https://github.com/astral-sh/uv) for dependency management (Python >= 3.9).

```bash
uv sync
```

Key dependencies: `pandas`, `numpy`, `matplotlib`, `yfinance`, `pandas-datareader`, `statsmodels`, `hmmlearn`, `scipy`.

## Running tests

```bash
uv run pytest
```

`test_backtest_engine.py` runs the engine end-to-end on synthetic data and on real cached price history (momentum and mean-reversion strategies), asserting on cost/return accounting and writing diagnostic charts to `plots/`.

Note: `DataLoader.data_path` is currently a hardcoded local path — update it if running on a different machine.

## Example

```python
import DataLoader
from Strategies.Momentum import MomentumStrategy
from BacktestEngine import BacktestEngine

tickers = ["AAPL", "MSFT", "AMZN", "GOOGL", "META", "NVDA", "JPM", "XOM", "JNJ", "PG", "V", "UNH"]
prices = DataLoader.getOHLCV("2015-01-01", "2025-01-01", tickers, "1d")

strategy = MomentumStrategy(skipMonths=1, lookbackMonth=12)
engine = BacktestEngine(strategy, prices)  # data_source must expose .iterate(start, end)
results = engine.run("2016-06-01", "2024-01-01")
```
